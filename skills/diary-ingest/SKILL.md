# Life Log からの取り込み

Life Log（静的 PWA。文章・音声・レシート画像 → Claude → この規約の Markdown → GitHub にコミット）は **raw 層（`diary/YYYY/YYYY-MM-DD.md` と `diary/YYYY/images/`）だけ**を書く。wiki 層（`stats/`・`summaries/`）の更新はこのスキルが担う。

## 手順

1. 目印のあるファイルを探す: `grep -rl "life-log-app: pending-stats" diary/`。無ければ「取り込み対象なし」と報告して終わる。
2. 日付の古い順に 1 ファイルずつ:
   1. 日記本文を読む。diary スキルの手順 4〜6（エンティティの抽出・名寄せ・個別ページ更新・index 更新）を、**本文に既に書かれているリンク先の名前**を正として実行する。本文のリンク先が既存ページの別名（例: 本文「サイゼ」、既存「サイゼリヤ」）だった場合は本文側のリンクを既存ページに直し、既存ページの「別名:」に追記する。
   2. 「支出」セクションがあれば finance スキルの手順 5（`stats/finance/` のカテゴリ個別ページと index）を実行する。日記側の表は既に完成しているので書き換えない（合計が明細の和と合わないときだけ直し、報告に書く）。
   3. 「要確認」と書かれた品目・金額があれば、推測で埋めずにそのまま残し、報告に列挙する。
   4. 進行中のトピック（`stats/topics/`）に関連する出来事があれば経過に 1 行追記する。
   5. 目印の行 `<!-- life-log-app: pending-stats -->` を本文から削除する。
3. 月初・年初チェック（diary スキルの手順 1）を 1 回だけ行う。
4. `diary-lint` があれば実行し、指摘を直す。
5. `git add` して `diary: ingest YYYY-MM-DD[, YYYY-MM-DD…]` のメッセージでコミットし、CLAUDE.md の規約に従って main に反映して push する。
6. 報告: 取り込んだ日付、新規に作ったページ、名寄せした名前、要確認の項目。

## 注意

- このスキルは Life Log が書いた本文を**要約し直さない**（利用者がアプリの確認画面で直した文章が正）。
- 秘密指定の内容はアプリ側で落としてある。本文に秘密らしきものがあっても推測で private に移さない（diary スキルと同じ方針）。
- 導入: このファイルを `ai-diary/.claude/skills/diary-ingest/SKILL.md` に置く。アプリ側の設定は不要。
